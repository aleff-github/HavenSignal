# Code of Conduct

HavenSignal is a security-focused project dealing with software intended for people in potentially vulnerable situations. Participation must remain professional, respectful, and evidence-driven.

## Expected behavior

Participants should:

- communicate respectfully and constructively;
- critique designs and code rather than people;
- make security concerns specific and reproducible;
- respect confidentiality around non-public vulnerabilities;
- avoid speculation about real reporters or alleged victims;
- use synthetic examples in public technical discussion;
- disclose conflicts of interest that materially affect a review;
- accept that security constraints may take priority over convenience or speed.

## Unacceptable behavior

The following is not acceptable:

- harassment, threats, discrimination, or targeted humiliation;
- publishing private information without permission;
- using project channels to identify, investigate, or accuse real individuals;
- posting exploit details for an unresolved vulnerability in public channels;
- pressuring maintainers to bypass documented security gates;
- intentionally introducing real sensitive data into issues, tests, fixtures, or pull requests.

## Enforcement

Maintainers may edit, hide, lock, or remove content and may restrict participation when necessary to protect contributors, reporters, or the project.

Sensitive conduct concerns should be raised privately with the maintainer rather than through a public issue when public discussion could cause additional harm.

Project decisions about code and security may be appealed through a documented issue or discussion when disclosure is safe, but security-sensitive information must remain private until coordinated disclosure is appropriate.
